GUMBI CONSTRUCTION WEBSITE
==========================

CONTENTS
- index.html          Home page
- about.html          About the company
- contact.html        Contact page and WhatsApp enquiry form
- style.css           Responsive styling, animations and 3D hover effects
- script.js           Navigation, WhatsApp messages, reveal effects and form logic
- assets/gumbi-logo.png
- assets/gumbi-flyer.png

HOW TO USE
1. Extract the ZIP file.
2. Keep all files and the assets folder together.
3. Open index.html in a browser to preview the website.
4. Upload the complete folder contents to your hosting public_html folder or GitHub Pages repository.

WHATSAPP
The website uses +27 75 188 8217 (international format: 27751888217).
Service buttons create a WhatsApp message specific to the selected service.
The contact form prepares a detailed WhatsApp enquiry for the visitor to review and send.

GOOGLE REVIEWS
The Google buttons open a Google Maps search for Gumbi Construction at the supplied Katlehong address.
A verified Google Business Profile / Place ID was not supplied, so the site does not display invented star ratings or fabricated customer reviews. Replace the Google Maps search URL with the exact Business Profile review link when the company provides it.

IMAGES
The supplied logo is used in the header and footer. The supplied flyer is included in assets as a reference.
The hero and construction image backgrounds load from Unsplash and therefore need an internet connection. Google Fonts and the embedded Google Map also need an internet connection.

BEFORE GOING LIVE
- Confirm the address and phone number are correct.
- Replace the Google Maps search links with the company's direct Google Business Profile review link, if available.
- Add real project photographs and client-approved testimonials when available.
- Test WhatsApp on a mobile phone.
